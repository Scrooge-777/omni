Fan control

Maximum fan speed
Runs both fans at full speed (HP OMEN / Victus BIOS). Turn off to return to automatic control.

Fan speed

Not seeing your fans?

Windows has no standard fan API. OMNI reads fans from the HP BIOS on OMEN/Victus laptops, and from LibreHardwareMonitor or HWiNFO on almost any other laptop or desktop. Start one of them and OMNI picks up every sensor it can see:

  • LibreHardwareMonitor: run it as administrator (its WMI provider is on by default).
  • HWiNFO: Settings → enable Shared Memory Support.

Standby is cached data Windows can hand out instantly, so it counts as available. Modified pages still have to be written to disk before reuse.

What "in use" is made of

From Windows' memory counters. "Shared & other" covers mapped files, shared DLLs, page tables and kernel stacks.

Standby list by priority

Windows reuses priority 0 first and keeps 5–7 (frequently used data) longest.

Commit & paging

Empty

These are RAMMap's "Empty" commands. Free memory is not faster memory: Windows refills the cache as you work, so use these for testing or to recover from a leak.

Processes by memory

Working set = RAM the process is using now. Private = memory only it can use (committed). "Trim" pushes its pages out; they come back as it touches them.
